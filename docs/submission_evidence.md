# Evaluator submission evidence

This bundle records only evidence that is present in the repository or produced by a
connected run. It does not include evaluator-test routes, labels, screenshots, or invented
metrics.

## Tracked implementation

- `src/classifier/predict.py`: saved `model.joblib` loading and candidate scoring contract.
- `src/hmm/`: Anand's decoder, network, adapters, and evaluation helpers.
- `configs/hmm_params.json`: tracked decoder parameters.
- `src/evaluator_pipeline.py`: API factory joining the saved classifier and HMM decoder.
- `tests/test_api.py` and `tests/test_evaluator_pipeline.py`: server-only label and candidate
  partition safeguards.

## Connected-run evidence

The connected classifier artifact directory, candidate JSONL, dataset, API log, and UI
screenshot are runtime inputs and are not present in this checkout. They must be captured
from a real `student_test` run on Laptop 1/Laptop 2 before submission. The API intentionally
returns a configuration error instead of producing synthetic predictions when those inputs
are absent.

When captured, attach only:

1. the actual model/preprocessor metadata and hashes;
2. the actual ten-trip `student_test` list;
3. the Laptop 1 `POST /predict` log and response;
4. the Laptop 2 result screenshot; and
5. measured metrics/maps generated by the connected pipeline.
